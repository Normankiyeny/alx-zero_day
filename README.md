# Eye Clinic Website

A responsive static website for an eye clinic, built as the foundation for a patient-facing clinic site.

## Included
- Professional landing page and clinic positioning
- Eye-care services section
- Optical frames catalogue with enquiry interaction
- Portfolio/showcase section for clinical and community work
- Appointment request form
- Responsive mobile layout

## Important production upgrades
The current appointment form is a front-end prototype. Before accepting real patient information, connect it to a secure backend/database and add appropriate privacy, security, consent, authentication and access controls. Replace demo frame prices/images with the clinic's actual catalogue and connect checkout/payment processing before selling online.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.
